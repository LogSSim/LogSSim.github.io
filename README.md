# Juyi Sheng — Academic Homepage

Static personal homepage for GitHub Pages, inspired by the clean academic layout of [Ziyi Wang's homepage](https://wangzy01.github.io/). No build step is required: `index.html` is the entry point.

## Update the page

- Edit the biography, news, publications, and links in `index.html`.
- Change spacing, colors, and mobile layout in `styles.css`.
- Replace `assets/portrait.jpg` with another square portrait if desired.
- The MP1 and GPA-RAM previews are silent, looping MP4 clips with static posters. `previews.js` pauses them when off-screen and respects the browser's reduced-motion preference.
- The browser and home-screen icons use Lazy Sheep (懒羊羊).

The profile details were supplied by Juyi Sheng. Publication details and links were checked against [Google Scholar](https://scholar.google.com/citations?user=g4PTCZ8AAAAJ), publisher pages, arXiv, and the linked project repositories in September 2026. Recent publications include one paragraph describing the method and the problem it addresses; the 2023 RCAR papers use title links only. Figures are extracted from the papers or their project websites. See [asset sources](assets/SOURCES.md) for figure, video, portrait, and icon provenance.

To publish, enable GitHub Pages for the `main` branch at the repository root.
